# Exercises — Practice from Brian P. Hogan's "57 Challenges to Develop Your Coding Skills"

This repository contains small Python exercises created to practice coding concepts inspired by Brian P. Hogan's book *57 Challenges to Develop Your Coding Skills*.

Each folder contains a tiny exercise (usually an `app.py` or similar). 

Included exercises (each is a separate folder):

- counting_characters
- mad_lib
- pizza_party
- printing_quotes
- rectangular_area
- retirement_calculator
- saying_hello
- simple_math

This repo is for practice and learning - credit to Brian P. Hogan for the challenge ideas.
